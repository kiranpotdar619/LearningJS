# IQ Notes — Prompt Template

Ask me any programming/tech concept question and I'll create a `.md` file in `IQ_notes/` with:

- A clean **table comparison** breaking down the concept
- A **visual pipeline / flow diagram** (text-based)
- A **real code example** tied to this project
- A **key takeaway** summary

## How to use

Just ask me a question like:

> "Explain the difference between synchronous and asynchronous code in JavaScript"
>
> "What's the difference between var, let, and const?"
>
> "Explain the event loop in Node.js"
>
> "What's the difference between `==` and `===` in JavaScript?"
>
> "Explain how promises work vs callbacks"

I'll save it as `IQ_notes/<topic>_IQ.md`.
